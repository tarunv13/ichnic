# Ichnic brand

**Name:** Ichnic (ICK-nick), from the Greek *ichnos*, a track or trace; ichnology is the science of reading tracks.
The project reads the traces wildlife crime leaves in public records. Formerly WildTrace (to October 2026), a name
many other projects use. The Python package, the command and the URL path stay `wildtrace` so links and scripts
keep working; a custom domain will carry the new name. Say it in full the first time: "Ichnic, the open atlas of
illegal wildlife trade".

**Motto:** Follow the trade.
**Descriptor:** Open evidence on illegal wildlife trade.
**Promise:** Evidence. Pathways. Restraint. Every number with its source and its limit; wildlife crime traced from
nature to its consequences; no one accused is ever named, and security never becomes militarisation.

## The mark

A trail crosses the globe from a **green** node (source: where nature is taken) through a **blue** node (transit) to
an **amber** node (market). They are the three roles of the Flows map, so the mark says what the platform does.

| File | Use |
| --- | --- |
| `web/brand/mark.svg` | the mark on light backgrounds |
| `web/brand/lockup.svg` | mark, wordmark and motto (README, slides, articles) |
| `web/brand/favicon.svg`, `favicon-32.png` | browser tabs |
| `web/brand/apple-touch-icon.png`, `icon-192.png`, `icon-512.png`, `icon-maskable-512.png` | home screens, the web app manifest |
| `docs/img/social-preview.png` (1280 x 640) | GitHub social preview (Settings > General > Social preview) and link cards |

Keep clear space of one node's width around the mark. Do not recolour the nodes: the colours carry meaning.

## Colour

Colours carry meaning across the Atlas, the static pages, charts and the mark.

| Role | Hex | Meaning |
| --- | --- | --- |
| Ground | `#edf1ef` | light, calm background (the Atlas is never dark by default) |
| Ink | `#0f1a17` | text |
| Cases | `#d6453d` | seizures, arrests, convictions |
| Species / source | `#218a5b` | species; where wildlife is taken |
| Trade / market | `#c27a06` | trade routes; where wildlife is bought |
| Places / transit | `#2563eb` | places; re-export hubs |
| Network | `#0f8b8d` | observatories, online trade, method |
| Investigate | `#6d4aff` | the link-analysis workbench |
| Evidence: strong / partial / gap | `#218a5b` / `#c27a06` / `#b3261e` | strength of open evidence |

The eight region colours used in Flows are a validated colour-blind-safe palette (see `web/js/flows.js`).

## Type and voice

System sans (Inter where available): heavy for numbers and headlines, regular for prose. Numbers are written in text as
well as drawn. Voice: [docs/VOICE.md](VOICE.md): answer first, then evidence, then the limit.
